=== پرتال مدیریت پیمانکاری AKPH ===
Requires at least: 6.0
Requires PHP: 7.4
Stable tag: 0.2.0
License: Apache-2.0

اپلیکیشن React پرتال (پروژه، قرارداد، صورت‌وضعیت، خزانه، تنخواه، خرید، انبار، حقوق، حسابداری) به‌صورت افزونه وردپرس.

== نصب ==
1. پیشخوان وردپرس ← افزونه‌ها ← افزودن ← بارگذاری افزونه ← فایل akph-portal.zip ← نصب ← فعال‌سازی.
2. منوی «پرتال AKPH» در پیشخوان اضافه می‌شود؛ دکمه «باز کردن پرتال در صفحه کامل» برنامه را بیرون از قالب سایت باز می‌کند (آدرس: /?akph_portal=1، فقط برای کاربر واردشده).
3. «پرتال AKPH ← تنظیمات»:
   - نسخه نمایشی (پیش‌فرض): داده نمونه کامل در مرورگر؛ تغییرات با تازه‌کردن صفحه پاک می‌شود؛ تعویض نقش (مدیر ارشد، حسابدار، مدیر پروژه، مدیر سیستم) از بالای صفحه برای آزمون تفکیک وظایف.
   - اتصال به افزونه «پایدار پورتال»: از مسیرهای paydar/v1 (/me، /projects، /accounting/*) می‌خواند و سند دستی را به‌صورت فرمان می‌فرستد. بقیه بخش‌ها تا ساخت فرمان‌های سرور فقط‌خواندنی‌اند (docs/API-CONTRACT.md).

== نکته ==
قالب پاسخ مسیرهای افزونه پایدار پورتال هنوز با کد آن تطبیق داده نشده است. اگر در حالت اتصال پیام «قالب پاسخ … نمی‌خواند» دیدید، به حالت نمایشی برگردید.
