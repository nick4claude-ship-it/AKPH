# آزمون‌های نسخه ۳.۰.۰

## نتیجه خودکار

- ۵۳ آزمون پروژه، مهاجرت، نقش‌ها و REST موجود: موفق.
- ۵۲ آزمون دفتر حسابداری: موفق.
- ۳۰ آزمون هسته تنخواه: موفق.
- ۱۵ آزمون DOM حسابداری: موفق.
- ۱۲ آزمون DOM تنخواه: موفق.
- نحو PHP با دستور زبان PHP 7.4 و نحو JavaScript بررسی شده است.

## محدوده آزمون تنخواه

آزمون‌ها دسترسی نقش‌ها و محدوده پروژه، صندوق/دسته، چرخه درخواست و آستانه تأیید، تفکیک maker-checker، شارژ از حساب منبع، هزینه پروژه، ثبت دقیق و idempotent دفتر، تلاش مجدد بعد از خطا، سقف در برابر درخواست‌های باز، مغایرت‌گیری و تاریخچه را پوشش می‌دهند. آزمون رابط با پاسخ‌های ساختگی و jsdom است و جای بررسی دیداری در مرورگر واقعی را نمی‌گیرد.

## محدودیت محیط آزمون

Backend با PHP WASM، شبیه‌ساز سبک وردپرس و PDO SQLite با تطبیق محدود SQL اجرا شده است. این کار callbackها و تراکنش‌های پایه را می‌آزماید، اما رفتار واقعی dispatch وردپرس، nonce، `dbDelta`، MySQL/MariaDB، قفل همزمان InnoDB، افزونه‌های کش و سازگاری قالب را ثابت نمی‌کند. PHP روی همه نسخه‌های runtime اجرا نشده است و نصب زنده روی هاست مشتری انجام نشده است.

پذیرش نهایی را ابتدا در staging انجام دهید: ارتقا از نسخه موجود، ماندگاری پروژه‌ها، ایجاد جدول‌ها و نقش‌ها، انتخاب واحد، تنظیم حساب و صندوق، workflow زیر/بالای آستانه، جلوگیری از سند تکراری، توازن دفتر، کنترل پروژه و نمایش دسکتاپ/موبایل.
